# Smart Complaint Management System

A web-based **Smart Complaint Management System** developed as a BCA project to manage student complaints efficiently.

## 📌 Project Overview

The system allows students to register, log in, submit complaints, view complaint details and track their complaint status. Administrators can manage complaints, update complaint status and publish notices.

## ✨ Features

### Student

* Student Registration & Login
* Student Dashboard
* Submit Complaint
* View Complaints
* View Complaint Details
* Track Complaint Status
* Edit Profile
* Change Password
* Logout

### Admin

* Admin Login
* Admin Dashboard
* View and Manage Complaints
* Update Complaint Status
* Mark Complaints as Completed
* Notice Management
* Logout

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML**
* **CSS**
* **MySQL**
* **XAMPP** – used to run MySQL locally

## 🗄️ Database

The project uses **MySQL** for storing student, complaint and notice data.

## 🚀 How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Start MySQL using XAMPP.
4. Create the required MySQL database.
5. Configure the database connection in the project.
6. Run the Flask application.
